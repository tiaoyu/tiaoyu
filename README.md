## 🌊 关于这条蝌蚪

- 🐟 池塘里的一条小蝌蚪，正在慢慢长大
- 🌱 在 pond 里，吃到食物半径就会变大——现实里也一样，每天喂自己一点新东西
- 🎮 做游戏也玩游戏：WebRTC 多人蝌蚪、微信里的鱼、OpenGL 的蛇……我的项目绕不开"水里的东西"
- 🌊 相信慢慢游，也能到很远的地方
- 🍜 偶尔浮上水面觅食（美食探险家认证）
